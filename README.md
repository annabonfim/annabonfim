`Python` `FastAPI` `RAG` `Llama 3.3 70B (Groq)` `Pydantic` `Azure`

`.NET 9` `C#` `Oracle` `JWT` `xUnit` `React Native` `Expo`

### [RailResponse](https://github.com/annabonfim/Python-API-RailResponse)
Serviço de alertas ferroviários com rotina agendada, integrando três APIs externas e banco Oracle, com notificação via WhatsApp.

`Python` `FastAPI` `Oracle` `APScheduler` `Twilio` `OpenWeather`

API REST de banco digital com contas, depósitos, saques e transferências PIX, em arquitetura em camadas com validação e tratamento centralizado de erros.

`Java 17` `Spring Boot` `Spring Data JPA` `Bean Validation` `Maven`

### [HumanLink](https://github.com/annabonfim/humanlink-front) &nbsp;·&nbsp; [ver no ar](https://humanlink-front.vercel.app)
Plataforma de resposta a emergências, conectando quem precisa de ajuda com quem pode oferecer, com autenticação, painel e listagem por urgência e localização.
